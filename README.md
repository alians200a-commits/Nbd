## الصوت — مهم

اختار صاحب المشروع **الصوت B** من حوار NotebookLM الثنائي. لم نرفع الصوت الخاص إلى المستودع العام.

التطبيق لا يستبدل الصوت B تلقائياً بصوت متصفح الجهاز، ولا يستخدم محرك `speechSynthesis` في نسخة الواجهة الحالية.

- يمكن للمعلّم تحميل **عينة B مفصولة** إلى المتصفح، للاستماع إليها مرجعاً.
- يمكن اعتماد **تسجيل منفصل لكل درس/مجسم**؛ لا يشتغل الصوت للطلاب إلا عندما يوفّر المعلّم الملف ويراجعه.
- لا يوجد بعد توليد حيّ لنصوص جديدة بنفس صوت B ولا محادثة صوتية مع نسخة مستنسخة من الصوت. تشغيل المرجع ليس توليداً.

## الحالة الفعلية

واجهة الفصول والمختبر والاختبارات وخزنة الأخطاء وجدول المراجعة هي نسخة تشغيل تجريبية. بعض المجسمات تأتي عبر روابط GitHub وتحتاج اتصالاً، وليست كلها نماذج تشريحية تفصيلية مستقلة لكل فقرة. تحتاج بعض أجزاء المنهج مراجعة علمية/بصرية إضافية.

## النشر

فعّل Pages في إعدادات المستودع على `main` و`/ (root)` لتجربة الواجهة على HTTPS. بعض الميزات لا تعمل عند فتح HTML مباشرة من مدير الملفات. التخزين الصوتي محلي في متصفح المستخدم، وقد يختفي بعد حذف بيانات الموقع.
