# نَبْض — الأحياء للثالث المتوسط

واجهة الطالب الجديدة **V9** مبنية على مكوّنات Ionic الأصلية، وأيقونات طبية من Health Icons (CC0)، ومجسمات من OrganUI.

- [index.html](index.html): صفحة التطبيق الرئيسية.
- [OPEN_SOURCE_SOURCES.md](OPEN_SOURCE_SOURCES.md): جميع مصادر GitHub والتراخيص والقيود.
- [v9/index.html](v9/index.html): نسخة التجربة الأولى.
- [tabler-archive.html](tabler-archive.html): تصميم Tabler السابق المحفوظ.

## وظائف الإصدار

يوفّر 11 فصلاً، و13 مجسماً مرجعياً من GitHub (تحتاج إنترنت)، واختباراً تدريبياً من 8 أسئلة، وخزنة أخطاء، وجدول مراجعة محلياً. لم تكتمل استنساخات صوت المعلّمة B أو كل النماذج التشريحية المفصلة أو المزامنة.

## النشر

GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root). هذه الخطوة قد تحتاج تفعيل صاحب المستودع. تتطلب الواجهة اتصال الإنترنت لتنزيل مكتبات Ionic والمجسمات. **لا تفترض أن الموقع منشور أو مجرّب على Android حتى تتم معاينته.**

## الأصول الخاصة

لا تحتوي النسخة العامة على صوت NotebookLM الأصلي أو كتب الوزارة والملزمة أو اقتطاعات الصفحات. لا تُعد هذه النسخة بديلاً عن الكتاب.
