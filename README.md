- التنقل: 5 وجهات على الهاتف (الرئيسية / الدروس / المختبر / الاختبارات / مراجعتي)، وقائمة إضافية قابلة للطي لبقية الخصائص.
- الفصول: مسار تعليمي من 11 فصلاً مع زرين مختلفين: فتح الشرح أو فتح المختبر.
- **الأيقونات الطبية حرفية من Health Icons (CC0)** مأخوذة من SVG المصدر في GitHub ومحفوظة في `public/assets/healthicons-anatomy.svg`. الأيقونات الوظيفية من مكتبة **Lucide** المفتوحة المصدر، لا رسومات مولدة بالذكاء الاصطناعي.
- الهوية: نظام ألوان فاتح؛ أزرق `#2354A5` وتركوازي `#0B746C` ونص `#182943` وخلفية `#F6F8FC`؛ خطوط عربية Tajawal وIBM Plex Sans Arabic.
- مراعاة القراءة واللمس: أزرار أساسية بارتفاع 44–52 بكسل، نص واضح، دعم RTL ومواضع تركيز مرئية وإيقاف الحركة الزائدة عند تفعيل تقليل الحركة.
- المختبر: عند فشل المجسم تظهر رسالة تعذّر حقيقية، ولا تُعرض معلومات الدماغ على أنها تفاصيل لعضو مختلف. لا ادعاء بأن كل المجسمات عالية الدقة أو أن السنوات الوزارية موثقة.
- نشر التطبيق: `.github/workflows/deploy-student-site.yml` يبني نسخة React ويضم أدوات التعليم القديمة غير الخاصة، ثم يحاول نشرها على GitHub Pages عند تفعيل Pages عبر GitHub Actions.

**حالة الاختبار:** أُجريت مراجعة للشيفرة والارتباط بين المكونات ومصادر الأيقونات. بناء React عبر GitHub Actions وفحصه بصرياً على هواتف 320–430 بكسل يحتاج تأكيد نجاح التشغيل، ولا يُعتبر الاختبار الميداني مكتملاً قبل ذلك.

المصادر المفتوحة: [Health Icons](https://github.com/resolvetosavelives/healthicons)، [Lucide](https://github.com/lucide-icons/lucide)، [Tabler Icons](https://github.com/tabler/tabler-icons)، [React](https://github.com/facebook/react).

## نظام الصوت

صاحب المشروع قدّم تسجيل MP3 مدته نحو 21 ثانية، بصوت اصطناعي من NotebookLM يتحدث عن **الفيزياء**. هو مرجع هوية صوت المعلّمة **B**؛ لا يجوز تشغيله على أنه شرح أحياء.

يتيح التطبيق إدخال المرجع بشكل خاص من هاتف الطالب/المعلّم ويطابق بصمة SHA-256 للملف المحدد. لا يُرفع التسجيل الخاص تلقائياً إلى المستودع العام. أي تسجيل أحياء جديد يُرفع بعد توليده ومراجعته ويُخزن محلياً، ولا يُستخدم صوت A أو صوت المتصفح الآلي بديلاً لصوت B.

**التوليد الصوتي الجديد بصوت B نفسه لم يُنفذ بعد**؛ يحتاج محرك استنساخ مناسب وفحص الترخيص والنطق العراقي. تهيئة 44 نصاً لا تعني إنتاج 44 ملف صوت.
