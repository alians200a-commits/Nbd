# نَبْض — مختبر الأحياء الذكي 2027

نسخة عامة تجريبية من المشروع، مبنية على الإصدار **V7.8**.

## ما رُفع فعلياً
- ملفات واجهة التطبيق الأصلية موزعة إلى ثمانية أجزاء نصية ضمن `chunks/`، ويجمعها ملف `index.html` أثناء فتح الموقع.
- الأطلس التشريحي المرجعي `atlas_real.html` وروابط مصادره.
- صفحات إرشادية وبعض واجهات استوديو إنتاج الصوت النصية.
- بيانات التدقيق والحقوق الموجودة في المستودع.

## ما لم يُرفع
- ملفات المجسمات المحلية بصيغة `GLB` (17 ملفاً) وملفات تشغيل JavaScript إضافية. **لهذا بعض وظائف التطبيق غير مكتملة على GitHub حالياً**.
- تسجيلات الصوت B الأصلية وملفات الكتب والملزمة والمواد المقتطعة منها، لأنها ليست مناسبة للنشر العام دون مراجعة الحقوق.

## GitHub Pages
من إعدادات المستودع: **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root)**.

لا تفترض أن موقع GitHub Pages مفعل أو أن التطبيق يعمل كاملاً حتى تختبره بعد التفعيل.

### ملاحظة علمية
بعض مجسمات الأطلس روابط خارجية تعتمد على الإنترنت، وجودها في الفهرس لا يعني تنزيلها إلى المستودع أو اختبارها جميعاً. هذا التطبيق تعليمي وليس أداة تشخيصية.
