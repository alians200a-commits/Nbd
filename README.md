# نَبْض — مختبر الأحياء الذكي

تطبيق تجريبي لمادة الأحياء للصف الثالث المتوسط في العراق.

## الواجهة الحالية

**واجهة 8.0 — مبنية على مشاريع GitHub مفتوحة المصدر حقيقية، وليست رسومات مُولّدة بالذكاء الاصطناعي.**

- القالب والقوائم والبطاقات والأزرار من [Tabler Starter](https://github.com/tabler/tabler-starter) و[Tabler](https://github.com/tabler/tabler) بترخيص MIT.
- أيقونات SVG أصلية من [Tabler Icons](https://github.com/tabler/tabler-icons) بترخيص MIT.
- عرض المجسمات من [Google model-viewer](https://github.com/google/model-viewer)، والمجسمات من مستودعات [OrganUI](https://github.com/organui).
- تفاصيل كل مشروع والرخص والمكونات: [OPEN_SOURCE_SOURCES.md](OPEN_SOURCE_SOURCES.md).

## روابط الملفات

- `index.html` — الواجهة الجديدة.
- `legacy.html` — نسخة قديمة احتياطية.
- `atlas_real.html` — الأطلس المرجعي السابق.
- `assets/nabd-app.js` — ربط الفصول والاختبارات والمراجعة والمجسمات.
- `assets/tabler-icons.svg` — المسارات الأصلية للأيقونات.
- `assets/nabd-tabler-config.css` — تعديلات عربية بسيطة على الثيم.

## الحالة الوظيفية

الواجهة الجديدة توفر تنقلاً بين 11 فصلاً، معرضاً يطلب 14 مجسماً ثلاثي الأبعاد من GitHub عبر الإنترنت، اختباراً تدريبياً للفصل الأول، خزنة أخطاء، وجدول مراجعة محلي. **هذه نسخة تجريبية وليست جميع مزايا المشروع النهائي**. لا يوجد تشغيل سحابي أو إرسال إشعارات ولي أمر بعد.

ملفات الكتب والملزمة وتسجيل NotebookLM الخاص غير منشورة في المستودع العام.

## GitHub Pages

افتح إعدادات المستودع، ثم Pages → Deploy from branch → main → root. يحتاج الموقع إنترنت لجلب مكتبة Tabler وعارض GLB والمجسمات. لا تدّع جاهزية الموقع العام قبل فحص عنوان Pages بعد التفعيل.

## الأمان والحقوق

حقوق مجسمات التشريح تختلف عن رخصة شيفرة OrganUI. يرجى قراءة [ملف المصادر والحقوق](OPEN_SOURCE_SOURCES.md) قبل إعادة توزيع أي نموذج أو استخدامه تجارياً. التعليم هنا مساند للكتاب وليس مصدراً طبياً تشخيصياً.
