`https://alians200a-commits.github.io/Nbd/`

## الأصول المستبعدة من المستودع العام

هذه النسخة لا تتضمن الملف الصوتي المرجعي B أو تسجيلات NotebookLM الأصلية، ولا ملفات الكتب أو الملزمة ولقطات الصفحات والرسومات المقتطعة منها؛ حفاظاً على الخصوصية وحقوق الملكية الفكرية. **النصوص والروابط الموجودة في الشيفرة قد تشير لهذه الملفات**؛ لن تعمل وظائفها إلا بعد توفير أصول تملك حق نشرها.

## ما هو جاهز وما ليس جاهزاً؟

- 17 نموذجاً محلياً تعليمياً مُبسّطاً داخل `models/`.
- أطلس مرجعي موسع بروابط لمصادر خارجية؛ **لم تُنزّل الملفات المرجعية عالية الدقة داخل هذا المستودع** ولم تُختبر جميع روابطها مباشرة.
- صفحات الاختبارات والتسميع والمحتوى التعليمي في إصدار تجريبي.
- مزامنة ولي الأمر والمعلّمة الذكية تحتاج خادماً مستقلاً ومتغيرات بيئة؛ GitHub Pages يستضيف ملفات ثابتة فقط.
- الصوت B غير متاح في هذه النسخة العامة لحماية ملف المستخدم.

المشروع غير معتمد طبياً ولا يحل محل المصدر الدراسي الأصلي. راجع `README_V7_8_AR.md` وروابط المصدر وترخيص كل مجسم قبل النشر التجاري.
