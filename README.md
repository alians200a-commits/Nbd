# نَبْض — مختبر الأحياء الذكي V7.8 (React + TypeScript)

تطبيق تفاعلي متقدم لمنهج الأحياء للصف الثالث المتوسط في جمهورية العراق، أُعيد بناؤه كلياً باستخدام **React 18** و **TypeScript** و **Vite** و **Tailwind CSS**.

## الميزات الرئيسية المحفوظة والمطورة

1. **الأطلس التشريحي ثلاثي الأبعاد (3D Atlas)**:
   - 25 نموذجاً تشريحياً مرجعياً عالي الدقة يغطي جميع فصوص وأعضاء المنهج عبر Google Model Viewer بتدوير 360° وتكبير كامل.
   - 16 مشهداً تفاعلياً لدراسة أجزاء العضو المنهجية مع معادلات الحفظ السريع ووضع الاختبار.

2. **دروس الكتاب الوزاري الكاملة (Curriculum Reader)**:
   - 11 فصلاً دراسياً و 132 صفحة كاملة بنصوصها المنهجية الأصلية.
   - رسوم ومخططات الكتاب المعتمدة مدمجة في صفحاتها المقررة.
   - قراءة صوتية ذكية للصفحات عبر واجهة تحويل النص إلى كلام (Speech Synthesis) وحفظ العلامات المرجعية.

3. **استوديو الأبحاث والتجارب العلمية (Research Studio)**:
   - 16 تجربة علمية تفاعلية تحاكي حركة الإيعاز العصبي، نبض القلب، دورة التنفس، واتساع بؤبؤ العين برسوم SVG حية وتحديد الفرضيات.

4. **محاكاة القوس الانعكاسي (Reflex Arc)**:
   - محاكاة دقيقة لخطوات الفعل الانعكاسي الخمس: المستقبل الحسي، العصب الحسي، الحبل الشوكي (المادة الرمادية)، العصب الحركي، وعضلة الذراع المنقبضة.

5. **بنك الأسئلة والاختبارات الوزارية (431 سؤالاً)**:
   - اختبارات الاختيار من متعدد مع التصحيح الفوري ونظام احتساب النقاط.
   - تصفية متقدمة حسب الفصول والموضوعات وسنوات الورود في الامتحانات الوزارية.

6. **محاكي الامتحان الوزاري الشامل**:
   - امتحان توقيتي مدته 20 دقيقة يحاكي أجواء الامتحان النهائي مع درجات تقييم شاملة ومراجعة تفصيلية للإجابات.

7. **استوديو الرسوم والمخططات الوزارية (18 رسماً)**:
   - تدريب على الرسوم التشريحية مع إمكانية إخفاء التأشيرات واختبار حفظ الطالب لكل جزء.

8. **خزنة الأخطاء وبطاقات الاستذكار (Spaced Repetition)**:
   - حفظ تلقائي للأسئلة الخاطئة لمراجعتها وتصحيحها.
   - 18 بطاقة استذكار سريع للمراجعة التكرارية.

9. **مراجعة ليلة الامتحان والملخصات المركزة**:
   - أهم التعاريف الوزارية، أسئلة "علل لما يأتي"، والمقارنات الإلزامية المقررة.

10. **محاكاة فسيولوجيا أجهزة الجسم الحيوية**:
    - قياس نبض القلب، معدل التنفس، ضغط الدم، وتراكم حامض اللبنيك والإعياء العضلي حسب درجات المجهود البدني.

11. **المعلّمة الصوتية وهندسة الصوت**:
    - اعتماد الهوية الصوتية B للمعلّمة مع أداة التسميع الشفهي والتعرف على الكلام الصوتي.

12. **لوحة متابعة أولياء الأمور والواجبات**:
    - متابعة نسبة إنجاز المنهج، سجل نتائج الاختبارات، وطباعة تقرير تقدم الطالب.

## المتطلبات والتشغيل

- **Node.js**: 22+
- **الحزم**: `npm install`
- **تشغيل خادم التطوير**: `npm run dev` (يستمع على المنفذ `3000`)
- **بناء التطبيق**: `npm run build`
