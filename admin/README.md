# لوحة الإدارة — إدارة صوت معلّمة نَبْض

> هذا مركز مهام الإدارة داخل GitHub، **وليس صفحة ضمن واجهة الطالب**. تحتاج صلاحية تعديل المستودع لتشغيل الإجراءات. التوليد يستخدم مفتاح Gemini المخزن في GitHub Actions Secrets؛ لا يوضع المفتاح في الكود أو المتصفح.

## مهام إدارة الصوت

| المهمة | رابط الإدارة | ماذا تفعل |
|---|---|---|
| توليد شرح جديد | [فتح نموذج التوليد](https://github.com/alians200a-commits/Nbd/actions/workflows/gemini-baghdad-voice.yml) | اضغط «Run workflow»، ثم أدخل معرّف الدرس والعنوان ونص الشرح المدقّق، أو اختَر ملف طلب موجوداً |
| الاستماع والتدقيق | [مراجعة التسجيلات الناتجة](https://github.com/alians200a-commits/Nbd/actions/workflows/gemini-baghdad-voice.yml) | افتح عملية التوليد الناجحة، ونزّل الحزمة الصوتية من قسم Artifacts واستمع إلى WAV |
| اعتماد ونشر التسجيل | [فتح نموذج الاعتماد](https://github.com/alians200a-commits/Nbd/actions/workflows/approve-nabd-gemini-voice.yml) | أدخل رقم عملية التوليد، وفعّل تأكيد المراجعة بعد الاستماع. لا ينشر التسجيل دون موافقة صريحة |
| إدارة مفتاح الخدمة | [المفاتيح السرية](https://github.com/alians200a-commits/Nbd/settings/secrets/actions) | الاحتفاظ بمفتاح GEMINI_API_KEY وتحديثه دون كشفه للمتصفح |
| مشاهدة التسجيلات المعتمدة | [مكتبة التشغيل المنشورة](https://github.com/alians200a-commits/Nbd/blob/main/public/nabd-voice/library.json) | عرض التسجيلات التي يحق للطالب استماعها فقط |

### معرّف الدرس

استخدم النمط `chapter1/lesson/01` للفصل الأول، الدرس الأول؛ وبنفس الطريقة لبقية الفصول من 1 إلى 11 والدرس من 01 إلى 04.

### سياسة النشر والصلاحيات

- **الإدارة فقط:** إعدادات التوليد، بيانات مفاتيح الخدمة، رفع التسجيلات، تدقيق النص، الاستماع للمسودات، الموافقة على النشر. صلاحية تشغيل مهام Actions تتطلب وصولاً ملائماً للمستودع.
- **الطالب وولي الأمر:** رابط الاستماع فقط من فهرس `public/nabd-voice/library.json`. لا تعرض شاشة الطالب أي رفع صوت أو اختيار نموذج أو تغيير متحدث أو صفحة إدارة.
- **لا نشر تلقائياً:** نجاح توليد Gemini ينتج ملفاً للمراجعة داخل Actions ولا يعد تصريحاً بنشره.
- **حدود الخدمة:** إضافة مفاتيح متعددة للمشروع نفسه لا تضاعف حصة Gemini؛ الحصة تُحسب على مستوى مشروع Google.
- **ملاحظة أمان ضرورية:** المستودع `Nbd` عام حالياً؛ يستطيع الآخرون قراءة شيفرته وملفات الطلبات وسجلات التنفيذ العامة، حتى لو لا يملكون صلاحية التوليد أو قراءة قيمة المفاتيح السرية. المعلومات التي يجب أن تبقى سرية بالكامل تحتاج مستودعاً خاصاً وخدمة إدارة محمية بتسجيل دخول وصلاحيات خادمية، وليس مجرد رابط مخفي.
- **الصوت الحالي:** «سلافات» من Gemini 3.1 Flash TTS معتمد كهوية أداء. لا تعيد تسميته «B» لأنه ليس استنساخاً لصوت B القديم.

### ما لا تفعله واجهة الطالب

يُستبعد من بناء الموقع العام `voice_production.html` و`audio-library.html` وسكربتات إدارة الصوت وفهرس بيانات الاعتماد الداخلي. يُسمح بنشر صوت الدرس المعتمد وفهرس الاستماع فقط.

هذا الفصل هو المستوى الإداري الآمن المتاح الآن ضمن بنية موقع GitHub Pages الثابتة. إنشاء لوحة إدارة خاصة داخل التطبيق نفسه بصفحة دخول فعلية يتطلب نظام هوية وصلاحيات وتخزين خادمي، وليس إخفاء زر فحسب.
