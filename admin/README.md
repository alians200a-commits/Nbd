# نَبْض — لوحة إدارة خاصة غير منشورة للطلاب

## الفصل الفعلي بين الإدارة والطلاب

- النسخة العامة من نَبْض على GitHub Pages تتضمن الدروس والاختبارات والصوت والصور **المنشورة فقط**.
- لوحة الإدارة تُبنى بشكل مستقل إلى **ملف HTML واحد**، ولا تُنسخ إلى ملفات الموقع العام نهائياً. فلا توجد صفحة `admin.html` في نشر الطلاب، ولا أجزاء جافاسكربت خاصة بها.
- يمكن لمسؤول المشروع تنزيل ملف اللوحة من مخرجات مهمة `Build private offline administrator app`، أو استلام الملف الجاهز مباشرة. بعد التنزيل يُفتح كملف على جهاز الكمبيوتر؛ لا حاجة لزيارة صفحات GitHub أثناء التحرير اليومي، لكن الاتصال بالإنترنت مطلوب لحفظ التغييرات.
- **تنبيه:** المستودع نفسه عام، فيستطيع الناس قراءة الشيفرة المصدرية إذا بحثوا عنها على GitHub. فصل واجهة الإدارة عن موقع الطلاب لا يخفي الشيفرة المنشورة في مستودع عام. صلاحيات تغيير المحتوى تبقى مقيدة بمفتاح مسؤول المستودع.

## تسجيل الدخول

1. افتح `NABD_ADMIN_PRIVATE.html` على جهازك.
2. عند أول استخدام، استعمل رمز وصول GitHub محدوداً لحساب المالك `alians200a-commits`، مخصصاً لمستودع `Nbd`.
3. صلاحيات الرمز المطلوبة: `Actions: Read and write` لتوليد واعتماد الأصوات، و`Contents: Read and write` لتحرير المحتوى والملفات ورفع الصور. `Metadata: Read` تلقائية.
4. لا تنسخ مفتاح Gemini إلى هذه الواجهة؛ يبقى محفوظاً في `GEMINI_API_KEY` بإعدادات Actions Secrets.
5. الرمز الإداري يبقى في ذاكرة النافذة فقط، بدون حفظ في التخزين المحلي؛ يُمسح عند تسجيل الخروج أو إغلاق الصفحة. لا ترسل الرمز في المحادثات أو لطلابك.

## المميزات المنفذة

- **المحتوى والصور**: تعديل عناوين ووصف وظهور الفصول، تعديل نصوص ٤٤ درساً والأسئلة والأجوبة، إضافة دروس وحذفها، نشر وإخفاء، رفع صور JPEG/PNG/WebP (حتى 2MB)، إضافة إعلانات مدعومة بالصور.
- **الظهور لدى الطالب**: فهرس `public/nabd-content/catalog.json` يحمل نسخة المحتوى التي تحكمها الإدارة. تعرض صفحة الفصول الشرح والصور والأسئلة من هذا الفهرس، وتعرض الرئيسية الإعلانات المنشورة. يبدأ الكتالوج بالمحتوى الموجود بالمشروع، ولا يمس النصوص الأصلية عند تحميله.
- **توليد الصوت**: اختيار فصل ودرس ونص الشرح وإرسال مهمة `gemini-baghdad-voice.yml`.
- **مراجعة الصوت**: الاطلاع على المحاولات والاستماع إلى الحزمة الناتجة واعتمادها بعد مراجعتها باستخدام `approve-nabd-gemini-voice.yml`.
- **تعديل ملفات المشروع المتقدم**: فتح وتعديل الملفات النصية المصرح بها (مكونات الواجهة، الأنماط، بيانات التعلم وغيرها) مع مقارنة بصمة النسخة قبل الحفظ، ويمكن الرجوع للتغييرات من سجل GitHub. الاستخدام المتقدم قد يكسر البناء ويجب تدقيقه.
- **فحص التطبيق**: اختبار وجود الصفحات والملفات المنشورة.
- **الربط المستقبلي**: يكتشف الفهرس تلقائياً مسارات الدراسة وملفات العرض الجديدة في المشروع، وأي وحدة إدارية جديدة بداخل `src/admin/modules/*.tsx` تظهر تلقائياً بعد بناء النسخة الجديدة.

### آلية الحفظ

تحرير النصوص والمحتوى والوسائط يكتبها المسؤول إلى المستودع باستخدام GitHub Contents API. كل حفظ ينشئ تعديلاً مرصوداً يشغّل بناء نسخة الطلاب تلقائياً؛ تظهر التعديلات بعد نجاح النشر وتحديث الصفحة. لا يتغير النص مباشرة إذا فشل الحفظ أو النشر. الصور المنشورة عامة، فلا تستعمل هذا القسم لبيانات حساسة.

## ملاحظات مهمة

- ملفات اللوحة نفسها ليست منشورة ضمن موقع الطالب. فتح الملف المحلي يحتاج متصفحاً حديثاً واتصالاً بالإنترنت لتشغيل خدمات الإدارة عبر GitHub REST API الذي يدعم CORS. لا نحتاج خادماً خاصاً إضافياً في هذه النسخة.
- نظام الصلاحيات يعتمد على الرمز الإداري المعتمد لدى GitHub، وليس على إخفاء الأزرار.
- هذا محرر للمحتوى والملفات، وليس مصمم صفحات بالسحب والإفلات؛ التعديلات المعقدة على البرمجة تبقى بالوضع المتقدم.
- لا تخزن رمز GitHub بمستند عام أو على جهاز مشترك.
