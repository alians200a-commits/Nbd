# نَبْض — لوحة إدارة التطبيق المدمجة

لوحة الإدارة الفعلية جزء من التطبيق نفسه: `admin.html`، بمظهر مستقل منسجم مع نَبْض ولا تظهر بأي مكان في قوائم الطلاب.

## الدخول

1. افتح لوحة الإدارة من رابط التطبيق نفسه: `…/Nbd/admin.html` (بعد تفعيل نشر الموقع). من الموبايل يمكن تثبيت اختصار على الشاشة الرئيسية.
2. الصق **رمز وصول GitHub محدود الصلاحيات** صادر من حساب مالك المستودع فقط. لا تُدخل مفتاح Gemini في المتصفح.
3. يتحقق التطبيق من هوية حساب المالك ومن الوصول للمستودع ومهام Actions ثم يفتح أدوات الإدارة. يحتفظ بالرمز في ذاكرة الصفحة فقط؛ يمسحه عند الخروج أو إغلاقها.

الرمز المطلوب يجب أن يخص مستودع `alians200a-commits/Nbd`، بصلاحية **Actions: Read and write** و **Contents: Read-only** و Metadata المتوفرة تلقائياً. إنشاء الرمز خطوة إعداد أولية من حساب GitHub؛ بعد ذلك تكون إدارة الصوت والمراجعة من داخل لوحة نَبْض.

**حد الحماية الحالي:** اللوحة جزء من موقع ثابت، لذلك لا يمكن توفير تسجيل دخول بكلمة مرور آمنة وحدها بدون خدمة تحقق خادمية. إخفاء الرابط ليس حماية؛ طلبات النشر تُخضعها GitHub لصلاحية الرمز. لا تحفظ الرمز بصورة دائمة في المتصفح أو الملفات العامة، ولا تستخدم رموزاً واسعة الصلاحيات.

## المميزات المكتملة

- **الرئيسية:** عدد الفصول والمميزات والتسجيلات وآخر العمليات.
- **توليد صوت:** اختيار فصل ودرس وعنوان وإدخال نص علمي مدقق، ثم تشغيل `gemini-3.1-flash-tts-preview` بصوت `Sulafat` الذي اعتمده صاحب المشروع. مفتاح Gemini مخزّن في GitHub Secrets ولا يمر بالمتصفح.
- **المراجعة:** عرض محاولات التوليد وفتح الصوت الناتج من الأرشيف لمراجعته قبل إعطاء الموافقة. يعتمد فقط عند ضغط المدير وتأكيد المراجعة.
- **المميزات والتحديثات:** فهرس مسارات التطبيق المستخرجة آلياً من `src/App.tsx` وملفات `src/views/*.tsx` مع سجل آخر التغييرات.
- **إعدادات وصلاحيات:** التحقق من حساب المالك وقفل لوحة الإدارة.
- **وحدات إضافية قابلة للتوسعة:** أي ملف يضاف إلى `src/admin/modules/*.tsx` ويصدر وحدة بشكل `{ title, description, Component }` يدخل تلقائياً إلى لوحة الإدارة عند البناء التالي. يوجد فحص تشغيل جاهز مثالاً.

## الربط التلقائي لكل تحديث لاحق

كل تحديث على `main` يشغّل بناء Vite الذي ينتج **صفحة الطالب و`admin.html` بنفس الإصدار**. تتجدد تلقائياً معلومات الأقسام ومكونات العرض المعتمدة وسجل التعديلات. إذا أضفنا ميزة تحتاج **أزرار إدارة خاصة** (مثل محتوى دروس أو مستخدمين) نضيف مكوّن إدارة واحداً داخل `src/admin/modules/` ليلتحق تلقائياً بالقائمة؛ لا يلزم تغيير تخطيط اللوحة الأساسي.

لا يمكن اختراع أدوات إدارة حقيقية لميزة جديدة دون منطق بياناتها وصلاحياتها؛ الاكتشاف التلقائي للميزة ليس بديلاً عن تنفيذ صلاحياتها.
