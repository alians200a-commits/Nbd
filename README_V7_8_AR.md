# NABD V7.8 — توسعة الأطلس التشريحي المرجعي

## ما الجديد؟
- توسيع الأطلس المرجعي من 6 نماذج إلى 24 نموذجاً.
- ربط معظم فصول المنهج بمرجع تشريحي ثلاثي الأبعاد أوضح.
- إضافة ملف `CURRICULUM_ATLAS_BRIDGE.json` لبيان الربط بين الموضوع المنهجي والمجسم المرجعي.
- إبقاء المجسمات التعليمية المحلية المبسطة داخل التطبيق الأساسي، وعدم حذفها.

## ملاحظة مهمة
هذه التوسعة حسّنت طبقة **المرجع التشريحي**، لكنها لا تعني أن كل نموذج أصبح مطابقاً 100% لكل فقرة مجهرية أو وظيفية داخل الكتاب. بعض الدروس ما زالت تحتاج المجسمات التعليمية المحلية مع المرجع الخارجي معاً.

## تشغيل سريع
1. افتح `atlas_real.html`
2. اختر العضو أو الموضوع.
3. إذا لم يُحمّل النموذج، افتح صفحة المصدر من الزر المباشر.
4. ارجع إلى `index.html` لمتابعة المختبر والتسميع.
